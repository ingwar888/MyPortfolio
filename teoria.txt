src - основная корневая папка для содержания остальных элементов архитектуры
     Основные папки:
    - app (управление всем домом(роутинг)(провайдеры)(основная App.tsx - точка входа)(main.tsx))
    - pages (каждая папка внутри pages = одна страница (Страницы не содержат логики. Они собирают только виджеты и фичи(header,footer)))
    - widgets (или Большие самостоятельные блоки, которые можно переиспользовать на разных страницах. Они могут содержать свою логику, свои фичи, быть сложными внутри)
    /widgets/header/
                -Header.tsx
                -Navigation.tsx
                -Header.module.css
    /widgets/Modal/
                -Model.tsx
                -ModalPortal.tsx
                -ModelStore.tsx
                -Modal.module.css
    Шапка ноги модалка работает одинаково на всех страницах 
    - features/ (действия пользователя (Конкретные действия, которые можно сделать: зарегистрироваться, отправить сообщение, посмотреть проект). Фичи можно вкл/выкл. Они живут своей жизнью и не зависят от страниц)                
    - entities/ (данные. Это сами данные без логики. Просто описание)
    /entities/skill/skill.type.ts
    - shared/(Инструменты (кирпичики - мелкие детали, которые используются везде))
    shared/ui/button
            -Button.tsx
            -Button.module.css
    shared/ui/input/
    shared/ui/container/
    Shared незнает о других папка (как ящик с инструментами, можно брать и пользоваться)
    Используется класс Button
    - styles/
        -globals.css #обои для вашего сайта
        -variables.css #палитры красок

Общение между собой правил:
    pages - может использовать виджеты, фичи, энтити и шаред
    виджеты - может использовать фичи, энтити и шаред
    фичи - может использовать энтити и шаред
    шаред не может использовать никого (самый низ)


- npm install react-router-dom нужен для рендеринга и перехода по страницам
